# WebUI 指南

在 AstrBot 插件页打开「云笺寻图」，就能看到网页面板。顶部是滑动胶囊，三个模式随意切：

```
快速获取 · 积木编程 · 调用记录
```

## 快速获取

取图 + 发图的主战场：

1. **选图源**：7 个图源单选；
2. **调参数**：各图源有自己的选项，具体分类见 [指令速查](/guide/commands)；
3. **填数量**：Lolicon 最多 20 张，Bing 8 张，其它 10 张；
4. 点「**获取**」或「**全随机**」；
5. 结果网格里**勾选想要的图**；
6. 下方**勾选目标群** → 「**发送**」一键送达。

> 若群聊列表显示为空，详见 [配置QQ适配器](/guide/deploy#2-配置-qq-适配器)

| 卡片按钮 | 作用 |
| --- | --- |
| ⛶ 全屏图标 | 打开全屏大图，可双指/滚轮缩放、拖拽 |
| ⓘ 图标 | 该图的调用详情（图源 / 指令 / API 返回） |

> 把当前参数存成配置预设？详见 [配置与积木编程](/guide/presets)

## 积木编程

把常用配置**拼成指令**，一句话召唤整套图：

1. 填**指令名**；
2. 从「可用积木」选配置预设 → 「添加」，排好步骤（可上移/下移/删除）；
3. 选**输出模式**；
4. 「保存指令」。

具体玩法、三种输出模式的区别，详见 [配置与积木编程](/guide/presets#积木编程-blocks)。

## 调用记录

WebUI、群指令、LLM 工具**三入口共用**同一份日志，最多保留 100 条（超了丢最旧的）：

- 列表：时间 / 图源 / 指令 / 群；
- 底部翻页 + 「刷新」；
- 点任意一条 → 详情弹窗（时间、用户、群、图源、指令、结果、用户消息、详细 API、API 返回结果）；
- 详情右上角 **复制**，整段带走。

> 目前已知本日志有许多问题，切勿完全信任

> 发现日志里 URL 显示「本地临时文件」？
> 部分随机源我们需保存为Base 64，因为图片不可复现

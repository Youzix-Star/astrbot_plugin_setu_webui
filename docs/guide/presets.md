# 配置与积木编程

把常用的取图参数存成**配置预设**，再把预设组合成**指令** —— 以后一句话就能召唤整套图。

## 配置预设（Presets）

1. 打开插件 WebUI「**快速获取**」，调好想要的参数（图源、分类、标签…）；
2. 填一个**配置名**（如 原神、风景、R18）；
3. 点「**保存**」→ 存成 `configs/<配置名>.json`。

### 使用

| 操作 | 方式 |
| --- | --- |
| 加载配置 | `/setu 配置名` |
| 查看已保存 | `/setu list` 或 WebUI 查看 |
| 删除配置 | WebUI 选中后点「删除」 |

> 配置名别带空格/特殊符号，不然命令会似掉喵😭

---

## 积木编程（Blocks）

1. 切到 WebUI「**积木编程**」；
2. 填**指令名**，从「可用积木」选一个配置预设 → 点「添加」；
3. 重复添加，排好步骤顺序（可上移/下移/删除）；
4. 选**输出模式**；
5. 点「**保存指令**」。

### 输出模式

| 模式 | 行为 |
| --- | --- |
| 随机选一个 | 从所有步骤里随机挑一个执行 |
| 全部（分条） | 每个步骤各发一张 |
| 全部（合并） | 所有图拼成一条消息发出去 |

### 使用

```
/setu 指令名
```

**举个栗子** 🌰：把「原神」「风景」「小狐狸」三个配置存成指令「今日三连」——

```
/setu 今日三连
```

随机模式就出一个，分条/合并就全发。群U想点单某个API？把配置名丢给他，`/setu 配置名` 人人可点。

> 一条预设可以被多条指令共用，补药重复造轮子哇 •ᴗ•

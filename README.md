# ☁️ 云笺寻图（astrbot_plugin_setu_webui）

在 WebUI 中通过 Lolicon / UApiPro / Bing / imgapi / dmoe / LoliAPI / 栗次元 获取随机图片，勾选群后一键发送；支持全随机、积木编程、调用记录、大图查看器与杂志风帮助海报。
